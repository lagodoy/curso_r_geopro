1.2 Bibliotecas e dados utlizados nesta lição

  • sf para trabalhar com dados vetoriais

Como exemplo, fica a sugestão de encontrar uma base de dados no GeoSampa que esteja no formato shapefile ou gpkg (base com dados vetoriais) e um arquivo do tipo raster no formato geotiff  no topodata do INPE.

1.3 Vetor

1.3.1 Carregando um arquivo vetorial no R

Para carregar dados vetoriais, pode ser utilizada a função read_sf() do pacote sf. Essa função recebe o caminho para um arquivo com dados vetoriais como parâmetro. No exemplo a seguir, o resultado é colocado na variável dados_vetor.

dados_vetor <- sf::read_sf(caminho_vetor_entrada)

No R, a função class() é utilizada para checar o tipo de dado armazenado em uma variável.

Como estamos trabalhando com um objeto do tipo sf, que é um dataframe com capacidade de armazenar dados geográficos, a função head() pode ser usada utilizada para listar as primeiras linhas da tabela de atributos associada aos nossos dados espaciais.

1.3.2 Salvando dados vetoriais

A função sf::write_sf() salva um dataframe espacial em um arquivo em disco. Os parâmetros básicos são, na ordem, o objeto que será salvo e o caminho completo com o nome do arquivo. A função trata automaticamente os dados de acordo com o tipo de arquivo (extensão) fornecido no segundo parâmetro. Também há a possibilidade de usar uma conexão com um banco de dados para salvar o objeto em uma tabela.

sf::write_sf(dados_vetor, caminho_vetor_saida)

1.4 Raster

1.4.1 Carregando um arquivo raster no R

1.4.1.1 Arquivo com apenas uma banda

terra::rast() é uma função para criar um objeto SpatRaster a partir do primeiro parâmetro dado. Aqui, um caminho para um geotiff em disco é passado para a função.

raster <- terra::rast(caminho_raster_entrada)

Após verificar o tipo retornado pela função, uma amostra dos pixels é extraída utilizando notação vetorial.

class(raster)

1.4.1.2 Dados multibanda

Os dados das bandas podem estar em apenas um arquivo ou em vários. O exemplo a seguir mostra como carregar três arquivos de uma banda e empilhá-los para criar apenas um objeto SpatRaster multibandas. Caso esteja usando os dados sugeridos neste capítulo, lembre-se de ajustar corretamente os caminhos dos arquivos nas variáveis para que a leitura seja feita de acordo com as bandas do visível.

red <- terra::rast(arquivo_red)
green <- terra::rast(arquivo_green)
blue <- terra::rast(arquivo_blue)

raster_rgb <- terra::rast(list(red, green, blue))

names(raster_rgb)

names(raster_rgb) <- c('red', 'green', 'blue')

1.4.2 Salvando dados raster

A função terra::writeRaster() recebe como seus parâmetros básicos, respectivamente, um objeto do tipo SpatRaster e um caminho completo (ou caminhos, caso os dados sejam multilayer e se deseje salvar cada banda separadamente) para salvar o arquivo.

O parâmetro overwrite é ajustado para TRUE, forçando a sobrescrita, caso o arquivo já exista.

terra::writeRaster(raster, caminho_raster_saida, overwrite=TRUE)
