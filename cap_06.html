6.4.1 Checando erros de topologia no R

Para completar o exemplo, um mapa indicando a validade das geometrias é apresentado.

zonas_od$erro <- ind_geometrias_erro
plot(zonas_od[, c('erro', 'geometry')])

É possível também capturar o motivo do erro da geometria, utilizandoo parâmetro reason ajustado para TRUE na função sf::st_is_valid().

zonas_od$motivo_erro <- sf::st_is_valid(zonas_od, reason=TRUE)

6.4.2 Erros de Topologia em Operações Espaciais

Se estiver usando os dados sugeridos, um erro de topologia deve surgir na tentativa de executar uma simples operação espacial entre vetores. Não se preocupe com entender a operação, caso ainda não tenha tido contato prévio com os fundamentos de operações espaciais.

zonas_od_selecao <- sf::st_intersection(zonas_od, limites_municipios_selecionado)
Error in (function (msg) : TopologyException: Input geom 0 is invalid: Ring Self-intersection at 338631.85606679588 7395714.3087706771 0

6.4.3 Correção de Erros de Topologia

6.4.3.1 Correção de Erros de Topologia com o sf

sf::st_make_valid()

zonas_od_corrigidas <- sf::st_make_valid(zonas_od)
ind_geometrias_erro <- !sf::st_is_valid(zonas_od_corrigidas)
zonas_od_corrigidas[ind_geometrias_erro,]

6.4.3.2 Alternativa para Corrigir Erros Topológicos em Polígonos

Um truque que costuma funcionar, para polígonos, é utilizar a operação de buffer com parâmetro 0 como raio.

zonas_od_corrigidas_buff <- sf::st_intersection(sf::st_buffer(zonas_od, 0), limites_municipios_selecionado)
Warning: attribute variables are assumed to be spatially constant throughout
all geometries
ind_geometrias_erro <- !sf::st_is_valid(zonas_od_corrigidas_buff)
zonas_od_corrigidas_buff[ind_geometrias_erro,]
