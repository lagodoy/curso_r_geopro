5.2 Bibliotecas e dados utlizados nesta lição

5.3 Preparação dos dados

Confira os CRS’s dos dois conjuntos de dados e os compatibilize adequadamente. Se estiver utilizando os dados sugerios da pesquisa OD de São Paulo, use o Sirgas 2000 UTM23S (EPSG:31983). Em nosso exemplo, os dados da zonas OD estão na variável zonas_od e os dos limites de municípios em limites_municipios.

5.5 Trabalhando com uma coluna da tabela de atributos

5.5.1 Acessando os Dados de uma Coluna

Cada coluna é um vetor e pode ser acessada com o operador $ após o nome da variável qu contém o dataframe.

5.7.2 Por Expressão

5.7.2.1 Exemplo 1 - Expressão Simples

A seguir, apenas o município de São Paulo é selecionado. A notação para essa seleção é simples. Basta usar o operador de igualdade de comparação com o nome escolhido, como no exemplo. O resultado será um vetor booleano com TRUE onde a string coincide. Esse resultado é então usado para fazer a seleção das linhas desejadas no dataframe, carregando as geometrias correspondentes nas linhas.

5.7.2.2 Exemplo 2 - Expressão Complexa

Com a base de dados de saúde, selecionamos somente os equipamentos públicos de alta complexidade.

Usamos o operador %in% e os operadores booleanos & (e) e | (ou).

saude_alta_complexidade <- dados_saude[(dados_saude$SEGMENTO %in% c('SAUGM', 'SAUGE'))
                                       & (dados_saude$TIPO =='HOSP' | dados_saude$TIPO == 'PATEN'), ]
